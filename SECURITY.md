# Sicherheit und Fehlermeldungen

## Einen Fehler melden

Öffne ein [Issue](../../issues) und schreib dazu:

1. Die **Version** — sie steht unten in der App unter den vier Punkten
2. Gerät und Browser
3. Was du getan hast und was passiert ist
4. Den Text aus dem **roten Fehlerkasten**, falls einer erschien

## Sicherheitslücken

Wenn du etwas findest, das die Daten anderer gefährden könnte, melde es bitte **nicht** öffentlich, sondern per E-Mail über das GitHub-Profil des Betreibers.

## Was die App bewusst nicht tut

- Sie fragt keine Zugangsdaten ab und speichert keine
- Sie sendet nichts an einen Server
- Sie lädt keinen fremden Code nach; alles liegt im Repository

## Wenn du die App selbst betreibst

Das Repository muss öffentlich sein, damit GitHub Pages kostenlos ausliefert. Öffentlich heißt **lesbar**, nicht änderbar — schreiben darf nur, wer als Mitarbeiter eingetragen ist.

Schütze dein GitHub-Konto mit einem starken, einmaligen Passwort und Zwei-Faktor-Authentifizierung. Wer dort hineinkommt, kann Code ändern, der anschließend auf den Geräten aller Nutzer läuft.

Schreib niemals Zugangsdaten, Namen von Mitschülern oder andere persönliche Angaben in den Quelltext. Das Repository ist für alle sichtbar.
